# 안전작업허가 분류 도구 — 배포 가이드

담당자가 매일 엑셀 3건을 업로드해 분류하고 "전체에 게시"를 누르면, 이 페이지 주소로
접속하는 모든 사람 화면에 실시간으로 반영되는 도구입니다.

**현재 상태: Firebase 설정(firebaseConfig, 보안 규칙) 완료. 남은 건 GitHub Pages 배포뿐입니다.**

---

## 1. GitHub 저장소 만들기

1. https://github.com/ktg1949 접속 → 우측 상단 **New**(또는 초록색 **New repository**) 클릭
2. 저장소 이름 입력 (예: `ptw-classify`) — **Public**으로 설정 (GitHub Pages 무료 사용 조건)
3. **Create repository** 클릭

## 2. 파일 업로드

1. 방금 만든 저장소 페이지에서 **Add file → Upload files** 클릭
2. 이 대화에서 받은 `index.html`과 `README.md` 두 파일을 끌어다 놓기
3. 하단 **Commit changes** 클릭

## 3. GitHub Pages 활성화

1. 저장소 상단 **Settings** 탭 클릭
2. 왼쪽 메뉴 **Pages** 클릭
3. **Source**를 `Deploy from a branch`로, **Branch**를 `main` / `/ (root)`로 설정 → **Save**
4. 1~2분 기다리면 페이지 상단에 다음과 같은 주소가 나타납니다:
   `https://ktg1949.github.io/ptw-classify/`
   (저장소 이름을 다르게 지으셨다면 그 이름으로 바뀝니다)

## 4. 배포 확인

1. 위 주소를 **새 브라우저 탭**에서 열기
2. 담당자가 이미 "전체에 게시"를 눌러둔 상태라면, 업로드 화면 없이 바로 분류 결과가 보여야 정상입니다
3. 안 보이고 업로드 화면만 뜬다면 아래 "문제 해결" 참고

---

## 매일 하는 일

**담당자**
1. 배포된 주소 접속 → 우측 상단 **"담당자 모드"** 버튼 클릭 → 암호 입력 (`123456`, `ADMIN_KEY`와 동일)
2. 엑셀 업로드 → 분류 확인
3. **"전체에 게시"** 클릭 → 접속해 있는 모든 사람 화면에 자동 반영

**팀원**
- 그냥 주소로 접속만 하면 됩니다. 업로드/게시 버튼은 보이지 않고, 조회·검색·필터만 가능합니다.

> 참고: 이 암호는 코드 안에 그대로 들어있어서 완전한 보안은 아닙니다. 팀원이 실수로
> 업로드·게시 버튼을 누르는 것을 막는 용도로 생각해주세요. 암호를 바꾸고 싶다면
> `index.html`의 `ADMIN_KEY` 값과 Firestore 보안 규칙의 값을 **둘 다** 같은 문자열로 바꿔야 합니다.

## 문제 해결

### "다른 경로로 열면 업로드 화면부터 다시 시작돼요"

가장 흔한 원인 3가지를 순서대로 확인하세요.

1. **컴퓨터에 저장된 index.html 파일을 더블클릭해서 열었다**
   → 이 경우 `file:///C:/...` 같은 주소로 열리는데, 브라우저가 로컬 파일에서의 인터넷 요청을
   차단해 Firebase 연결이 안 될 수 있습니다. **반드시 3번에서 만든 `https://ktg1949.github.io/...`
   주소로 접속**하세요. 로컬 파일 더블클릭은 테스트용으로만 쓰고, 실제 공유는 항상 웹 주소로 하세요.

2. **캐시된 옛날 버전이 보이는 것**
   → 주소창에서 새로고침을 **Ctrl+Shift+R**(강력 새로고침)로 눌러보세요. 일반 새로고침은
   브라우저가 저장해둔 옛날 파일을 다시 보여줄 수 있습니다.

3. **저장소에 올라간 index.html이 옛날 버전(Firebase 연동 전)**
   → GitHub 저장소에서 `index.html`을 열어 `firebase.initializeApp` 문구가 있는지 확인하세요.
   없다면 이 대화에서 받은 최신 파일로 다시 업로드(Upload files → 같은 이름으로 덮어쓰기)하세요.

### "게시했는데 다른 사람 화면에 안 보여요"

- Firebase Console → Firestore Database → 데이터 탭 → `ptw` 컬렉션 → `latest` 문서를 열어
  실제로 데이터가 저장됐는지 확인하세요. 없다면 게시가 실패한 것이니 index.html의
  `firebaseConfig`가 정확한지 다시 확인하세요.
- 브라우저에서 F12(개발자 도구) → Console 탭에 빨간 오류가 있는지 확인하세요.

### "게시 버튼이 실패해요"

- Firestore 규칙이 올바르게 게시됐는지 Firebase Console → Firestore Database → 규칙 탭에서
  확인하세요. `allow write: if request.resource.data.adminKey == "123456";`
  부분이 index.html의 `ADMIN_KEY` 값과 똑같아야 합니다.

└── README.md    ← 이 배포 가이드
